# منصة إدارة خدمات مدارس الأحد — Multi-Tenant Sunday School SaaS

منصة سحابية متعددة الفصول (Multi-Tenant SaaS) لإدارة خدمات مدارس الأحد القبطية، مع عزل كامل لبيانات كل كنيسة وفصل، ولوحة تحكم مركزية لصاحب الـ Environment، وبوابة تسجيل وشات فوري لأمناء الفصول والمتقدمين.

## المميزات الأساسية
- **عزل كامل لكل مساحة خدمة (`workspaces/{workspaceId}`):** لكل فصل اسمه، كنيسته، شعاره الخاص، آية الفصل، مخدوموه، خدامه، جداوله، وإعلاناته.
- **لوحة تحكم صاحب الـ Environment:** إنشاء فصول جديدة فورياً، مراقبة الغرف النشطة أو تعليقها، معاينة أي فصل، واعتماد طلبات المتقدمين بنقرة واحدة.
- **مركز تواصل أمناء الفصول والشات الفوري:** قناة جماعية لجميع أمناء الفصول + محادثات مباشرة مع صاحب المنصة.
- **بوابة الخدمة الشاملة:** بوابة المخدومين وأولياء الأمور، لوحة الخدام، الحضور والغياب، النقاط، التصدير والاستيراد عبر Excel، جدول الخدمة الشهري بـ 7 فقرات، لوحة الافتقاد الأسبوعي، وسجلات التدقيق وأمان الحسابات.
